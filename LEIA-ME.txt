FRESTA — O Lado de Dentro | Capítulo I | versão 0.1.0

PUBLICAR NO GITHUB PAGES
1. Extraia este ZIP.
2. Envie o CONTEÚDO extraído para a raiz do seu repositório: index.html, assets, favicon.svg, .nojekyll e THIRD_PARTY_NOTICES.txt.
3. No GitHub, entre em Settings > Pages.
4. Escolha Deploy from a branch, branch main e pasta / (root).
5. Salve e aguarde o GitHub informar o endereço publicado.

Este é o build pronto: não é necessário instalar Node.js para publicá-lo.
Para editar ou usar GitHub Actions, use FRESTA_Codigo_Fonte.zip.

REQUISITOS
Computador com teclado, mouse e navegador com WebGL 2.
Não abrir index.html por duplo clique. Use o GitHub Pages ou um servidor HTTP local.
Sem controles touch nesta versão.

CONTROLES
WASD andar | Mouse olhar | E interagir | Shift correr
C/Ctrl agachar | F lanterna | Segurar F 2 s dínamo, se a bateria acabar
Botão direito concentrar luz | V trocar câmera | M planta | Tab diário
B usar pilha | Esc pausa | F3 medidor de desempenho

SALVAMENTO
Use o gravador na sala azul da Zeladoria. As gravações ficam neste navegador/endereço.
Exportar gravação baixa a última fita ou checkpoint já salvo. Não grava progresso remoto.
